Pieuvre </>

Les tentacules dessinent une balise de code </>. Le jeu de mots « tentacode » devient visuel — malin et très orienté dev.

Toutes les pistes héritent automatiquement des couleurs du thème (currentColor pour le corps, variables pour yeux + pupilles), donc elles fonctionnent telles quelles dans le header comme dans le footer. Dis-moi le numéro retenu et je l'intègre — on peut aussi ajuster l'épaisseur des traits, l'expression, ou mixer deux idées.
